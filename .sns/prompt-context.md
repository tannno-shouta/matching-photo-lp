# LP Context — 福岡垢抜けマッチングフォト サービス情報

## サービス概要

**福岡垢抜けマッチングフォト** は、福岡発のマッチングアプリ向けプロフィール写真撮影サービス。
単なるカメラマンサービスとは違い、**撮影前の "垢抜け"（服装・髪・眉・表情）まで一貫プロデュース**するのが特徴。

哲学: **「写真は結果。その手前の "垢抜け" まで含めてプロデュースする」**

- **Light**: シンプル撮影プラン
- **Standard**（推奨）: 撮影 + 服装・ヘア・表情ディレクション、好み女性から逆算したロケ選定、アプリ攻略相談、プロフィール文添削
- **Premium**: ファッションコンサルによる服装購入同行（天神エリア 1-2h）、撮影後の "垢抜け" フォロー相談、優先予約特典

1. **"垢抜け" から撮影までオールインワン型**: 服装・髪・眉・表情、撮る素材そのものを整えてから撮る

## 文体ルール（最重要・厳守）

- **基本タメ口**：です・ます調は使わない
- **断言は体言止め**：「〜だ」「〜だよ」「〜だね」を抜く
  - ❌「最短距離が、写真だ。」 → ✅「最短距離が、写真。」
  - ❌「それが現実的な近道だ。」 → ✅「それが現実的な近道。」
- **地の文を基本にする**：短文＋改行の連続（ポエム調）で構成しない。1ブロック2〜3文つなげてよい
- **NG 語尾**：「マジで」「〜じゃん」「〜やん」（痛いカジュアル）
- **OK 語尾**：「〜てる」「〜になる」「〜と思う」「〜が多い」「〜という話」「〜らしい」
- 一人称：「自分」または明示しない（主語省略多め）

## ブランド固有語彙（使ってOK・連発しない）

- 「**垢抜け**」: サービスの中核キーワード。撮る前の素材を整える行為
- 「**素材**」: 服・髪・眉・表情の総称
- 「**入口**」: マッチングアプリの一覧画面・第一印象
- 「**ディレクション**」: 撮影前の総合プロデュース
